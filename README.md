# 🦅 Bird Species Observation Analysis

Analysis of bird species distribution across 11 US National Parks.

## Tech Stack
- Python, Pandas, SQLAlchemy
- Google Colab (analysis)
- Streamlit + Plotly (dashboard)
- SQLite (data storage)

## Project Structure
notebooks/   → Data cleaning & EDA (Google Colab)
app/         → Streamlit dashboard
data/        → Dataset info
output/      → Cleaned data
